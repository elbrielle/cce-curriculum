# CCE Curriculum - Lessons Learned & Handoff

## 1. The "Stanley Standard" (Core Principles)
* **Student-Facing Language:** Must be active, uncluttered, and free of all developer/teacher jargon. Do not use phrases like "licensed page images" or administrative TEKS codes in student materials.
* **Explicit Directions:** Do not leave response locations ambiguous. Explicitly name the exact platform and location (e.g., "Write your recommendation in your **CCE Work OneNote** tab").
* **Slide Decks:** Slides must NEVER contain teacher planning or instructional language (e.g., "do not let students guess"). Slides must include clear countdown timers, concrete partner roles, and visual UI icons (e.g., Hats & Ladders logos) to support Emergent Bilinguals.
* **Teacher Facilitator Guides:** The Week 1 Days 2-5 flows now use the natural, expansive, supportive Avil model. Future agents must preserve:
  * **Conversational, Actionable Steps:** Use bullet points with clear verbs (e.g., "Welcome students to class. Prompt students with a class discussion around...").
  * **Explicit Questioning:** Quote the exact questions teachers should ask (e.g., *"If you could create and 3D print something... what would you make and why?"*).
  * **Step-by-Step Activity Instructions:** Do not summarize the activity; list the exact steps the teacher needs to guide the students through (e.g., "1. Sign in to Tinkercad. 2. Select Create New Design...").
  * **Clear Media & Vocab Cues:** Explicitly list when to pause for vocabulary review or when to reference a specific slide/video.

## 2. OneNote Automation & Formatting (Critical)
* **OneNote Is a Parallel Teacher Route:** Native OneNote pages are owner/teacher-selectable derivatives of the shared worksheet, not replacements for printable PDFs or an existing private Canvas response. Preserve equivalent routes so the curriculum outlives any one teacher or platform choice.
* **One Response Home Per Student:** The teacher chooses OneNote, paper/PDF, or the approved private Canvas response before class. Students complete the cognitive work once in the chosen route; never make them copy the same answer into a second system.
* **No Stagnant PDFs:** We do not drop raw PDFs as backgrounds for students to write over.
* **Native HTML Tables:** All worksheets (like the 5-Stage Checklist or Career Research) must be translated into native HTML tables so they can be pushed via the Microsoft Graph API.
* **Absolute Widths:** OneNote ignores CSS percentages. You MUST use absolute pixel widths (`<table width="850">`) to prevent the tables from becoming awkwardly narrow.
* **Single Page Philosophy:** When OneNote is the selected route, combine daily worksheet tasks and the Exit Ticket into a single page inside the `CCE Work` tab to reduce clicks. Keep the equivalent shared PDF/paper or Canvas route available for other teachers.
* **Strategic EB Scaffolds, Not Blanket Translation:** Keep the grade-level task and English language goal intact. Add a focused word bank, meaningful visual or model, oral rehearsal, and optional sentence frame at the places where language load could hide content understanding. Translate essential directions, safety language, or high-value terms when it improves access, but do not mirror every line in Spanish or assume all multilingual learners share one home language. Make supports easy for a teacher to add, fade, or extend based on actual student language evidence.
