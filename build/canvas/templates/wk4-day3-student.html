Build a help desk troubleshooting sequence

Use MakeCode or the equal paper logic route to make Button A advance steps and Button B show FIXED.

Major-grade evidence begins today: every team completes the Help Desk Program Evidence sheet. Hardware is not part of the score.

1. Get a scenario and name the project

Open the scenario cards. Name the project Period - Team - Help Desk. Use the same assigned Chromebook on Days 3-5.

2. Build or trace the logic

  1. On start: set step to 1 and show “Help Desk Ready.”
  2. Button A: show the current step, then change the variable. After Step 3, return to Step 1.
  3. Button B: show “FIXED.”
  4. Test A four times and B once.
