Teacher Facilitator Guide · 1SW Wk0 Day 3

Work Values and Building Blocks

H&L Core B · 50 minutes · TEKS d(1)(A), d(1)(B)

Presentation: Download PowerPoint · Make a Google Slides copy. Speaker notes include timing, sources, the model, the pivot, and recovery steps. This guide contains the full lesson.
Do not assign duplicate responses. H&L stores profile results, FYF pp. 9-11 hold the Building Blocks inventory, and the notebook holds one connection.

Open the student guide

Before students arrive

  • Open the Day 3 presentation and Student Guide, then confirm H&L. The presentation includes the required Exploring Your Work Values frames; do not open a second Climber Notes deck.
  • Set one FYF workbook per student to pp. 9-11.
  • Prepare the optional Building Blocks word bank and bilingual support; default copies: 0.
  • Students need the private page Work Values + Building Blocks - Day 3 or physical equivalent.

Complete model

Value: Relationships
Building Block: I help my younger cousin with homework.
Skill: Explaining clearly and patience.
Possible cluster: Education & Training, because those careers use clear explanations and patience.

Non-model: “I play games. It builds gaming. Any cluster.” Ask what the student actually does and what skill is visible.

50-minute flow

1. Work-value opener · 5 minutes

Private choice, then two optional shares. Name the values inside the reasons.

2. Discover Your Work Values · 15 minutes

Four-minute model, then the H&L activity. Students note top values and one expected/surprised reason. Minute 20: every student is in the activity or has the fixed list and a provisional choice.

3. FYF Building Blocks · 17 minutes

Use pp. 9-11 and the complete model. Students record three real experiences and one visible skill each. Run one structured partner round or private teacher/self-check. Minute 37: three experiences + skills.

4. Save profile inputs · 8 minutes

Students save three Building Blocks and locate initial recommendations. Never invent missing recommendations.

5. One connection + cleanup · 5 minutes

Value + Building Block + possible cluster + because. This is the exit evidence; no separate ticket.

Pivot, trim, and recovery
  • If H&L takes more than 20 minutes, finish FYF and the notebook connection; move app saves/recommendations to Friday.
  • No H&L: fixed values + provisional result; no shared account.
  • No workbook: one paper/notebook page with the four FYF categories; accept it without recopying.
  • Protect three Building Blocks and the final connection. Trim partner talk and recommendations first.
Access and privacy

Offer read-aloud, word banks, oral rehearsal, speech-to-text, and a private response. Students may use a school, hobby, or fictional example. Never require family, health, financial, immigration, or caregiving disclosure.
