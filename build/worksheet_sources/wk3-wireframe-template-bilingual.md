## Symbol Key / Clave de Símbolos

- **A box with an X inside:** an image, an icon, or a video
*Una caja con una X adentro: una imagen, un icono o un video*
- **Horizontal lines:** text or paragraphs
*Líneas horizontales: texto o párrafos*
- **A solid rectangle or oval:** a button the user can click
*Un rectángulo u óvalo relleno: un botón que el usuario puede oprimir*
- **Three stacked lines:** the main menu
*Tres líneas apiladas: el menú principal*

**Words for your labels / Palabras para tus etiquetas:** Header = Encabezado · Footer = Pie de página · Navigation = Navegación · Button = Botón · Screen = Pantalla · Main Menu = Menú principal · User = Usuario · Feature = Función
