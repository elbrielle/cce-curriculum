You are a technician at a fruit factory. The machine that puts label stickers on the fruit has stopped. The whole line is stopped with it. Work the checklist a real technician would work.

**Stage 1 is filled in for you as an example. Fill in the last four stages.**

The clues:

- The machine made a clicking noise before it stopped.
- There is no smoke, no sparks, and no leaks.
- The other machines on the line still run fine.
- The sticker roll is in place, but no labels come out.
- The operator says the machine ran fine until a new roll of labels was put in.

| Stage | What I would do as the technician |
|---|---|
| **1. Identify the Problem.** Which part is not working? What was the machine doing right before it stopped? | The label machine stopped. It made a clicking noise first. There is no smoke, no sparks, and no leaks. The other machines still run. The sticker roll is in place, but no labels come out. A new roll of labels went in right before the machine stopped. |
| **2. Analyze Possible Causes.** Is it mechanical, like a worn part or jammed gears? Electrical, like bad wiring or a sensor? Operator error, like a wrong setting? Something else? | |
| **3. Implement a Solution.** What is the best repair to try first, based on your causes? | |
| **4. Test and Observe.** How will you check that the machine works again? What will you do if it still does not work? | |
| **5. Prevent Future Breakdowns.** What would keep this from happening again? Operator training? More maintenance? | |

**Think about it.** Which clue helped you the most? Was this problem more likely a machine issue or a human mistake?
