**Print one sheet, cut out all fifteen cards, and keep each row's three cards together.** Give a team the row that matches its Help Desk scenario card.
*Imprime una hoja, recorta las quince tarjetas y guarda juntas las tres tarjetas de cada fila. Dale a cada equipo la fila que va con su tarjeta de escenario.*

**Your job.** The three steps are out of order. Put them in the order a help desk tech would really try them. The fastest check goes first.
*Tu trabajo. Los tres pasos están desordenados. Ponlos en el orden en que un técnico de mesa de ayuda los probaría de verdad. La revisión más rápida va primero.*

| Scenario / Escenario | Card A / Tarjeta A | Card B / Tarjeta B | Card C / Tarjeta C |
|---|---|---|---|
| **1. Printer not working** / *La impresora no funciona* | Restart printer / *Reiniciar la impresora* | Check power cable / *Revisar el cable de poder* | Check paper tray / *Revisar la bandeja de papel* |
| **2. Wi-Fi disconnected** / *El Wi-Fi está desconectado* | Forget and reconnect network / *Olvidar y reconectar la red* | Check airplane mode and Wi-Fi / *Revisar modo avión y Wi-Fi* | Restart the laptop / *Reiniciar la computadora portátil* |
| **3. Software crashing** / *El programa se cierra solo* | Check for updates / *Buscar actualizaciones* | Close and reopen app / *Cerrar y abrir el programa* | Restart computer / *Reiniciar la computadora* |
| **4. Computer won't turn on** / *La computadora no prende* | Test the outlet or charging light / *Probar el enchufe o la luz de carga* | Try an approved spare charger or escalate / *Probar un cargador aprobado o escalar* | Check charger and cable / *Revisar el cargador y el cable* |
| **5. Password reset** / *Restablecer la contraseña* | Use the official password reset link / *Usar el enlace oficial para restablecer* | Check caps lock / *Revisar la tecla de mayúsculas* | Verify the username and account / *Verificar el usuario y la cuenta* |

**Talk it out before you commit.** "We put _____ first because it takes the least time, and we put _____ last because _____."
*Háblalo antes de decidir. "Pusimos _____ primero porque toma menos tiempo, y pusimos _____ al final porque _____."*
