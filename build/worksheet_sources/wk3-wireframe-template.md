Use one sheet for each screen you want to plan. Keep it simple. This is not about making it pretty. It is about showing exactly how the app works.

## Symbol Key

- **A box with an X inside:** an image, an icon, or a video
- **Horizontal lines:** text or paragraphs
- **A solid rectangle or oval:** a button the user can click
- **Three stacked lines:** the main menu

**Before you trade with your partner, check both:**

- [ ] Every button is labeled with what happens when you click it.
- [ ] A first-time user can tell where to click next.
