## Run 1: Basic sequence

Alpha moves Gate 1 to the R1 hold marker. Bravo moves R2 to Gate 2. Charlie remains at Gate 3.

**Success:** one aircraft moves at a time, and both moving aircraft use Name, Route, Repeat, Confirm, and Log.

---

## Run 2: Two requests

Alpha requests Gate 1 to R1. Bravo requests Gate 2 to R2 at the same time.

**Constraint:** sequence the requests and keep one aircraft at a hold marker.

**Success:** state the order, repeat each direction, and log why one aircraft waits.

[[pagebreak]]

## Run 3: Runway closure

R1 is closed before movement begins. Alpha and Bravo must use an available route without crossing another moving aircraft. One gate is temporarily blocked.

**Success:** use the alternate route, change the sequence, and explain the revision.

---

## Individual scenario

Alpha and Bravo request movement at the same time. Taxi A is blocked.

Write which aircraft moves first and why, the full five-step classroom call, and one two-minute improvement goal.

**Boundary:** these are fictional classroom constraints, not real FAA procedures.
