## 4. Five-step classroom protocol

1. **Name:** address one aircraft.
2. **Route:** state start, destination, and path.
3. **Repeat:** mover repeats the direction before moving.
4. **Confirm:** controller confirms or corrects.
5. **Log:** recorder marks result and breakdown.

Model call:

> “Alpha, move from Gate 1 to the R1 hold marker by Taxi A.”
