## Before Class

Provide one device per student; no grouping is required. Project the supplied claim-versus-proof model and fixed cards. Print one four-page fallback only for each paper or enlarged-route student. Collect one Canvas response or one packet, not a separate exit. No live occupation search is required.

## Warm-Up (5 min)

Name one skill a pilot, nurse, and automotive technician use. Require a task example before accepting the answer.

## Activity 1: What Counts as Proof? (8 min)

Model one row: **attention to detail** transfers because a software developer checks code changes, a nurse verifies supplied patient information and orders, and an automotive technician follows an inspection checklist. “They all need it” is a claim, not evidence.

## Activity 2: Six-Career Comparison (25 min)

Students compare four skills: analytical reasoning, communication, attention to detail, and teamwork. For each skill they:

1. mark the careers where the fixed task card supports the skill;
2. copy two different task examples;
3. explain what stays the same across the two careers; and
4. explain what changes because the technical setting is different.

This replaces the old 48-cell grid. Students still compare six careers, but each multi-sentence explanation receives its own writing block.

## Activity 3: Pattern Claim (7 min)

Students choose the skill with the strongest six-career evidence and write a claim using three task examples. They may argue that another skill transfers less broadly when they cite the cards. Do not require the unsupported claim that employers always value soft skills more than technical skills.

## Exit Check (5 min)

**EXIT TICKET** (Short Constructed Response) · [Printable PDF](../../resources/exit-tickets/4sw-wk6-day2-prove-that-a-skill-transfers.pdf):

1. Choose two careers from different clusters.

2. Name one transferable skill. Use one specific task from each career and explain the common behavior.

*(d(4)(B))*

## Monitoring and Supports

- **Minute 13:** responses name tasks, not titles alone. If more than one-third list only skill names, annotate the supplied model together.
- **Minute 29:** two comparisons are complete. **Minute 41:** all four comparisons and three task examples are present.
- Safe trim: use the same strongest three examples in the pattern claim and independent exit instead of generating new examples.

- A career title alone is not proof; require the task.
- Read one card at a time and highlight the action verb.
- Accept phrases in the evidence boxes and complete sentences only for the final claim.
- Absence route is identical and independent; no partner, performance, or login is required.
