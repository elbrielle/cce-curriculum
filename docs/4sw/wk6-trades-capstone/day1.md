## Before Class

1. Place one FYF workbook and one device per student. Post one three-page fallback only for each no-workbook, enlarged, absence, or Canvas-annotation student.
2. Project the four fictional clue sets. Tell students that the workbook's repeated second “Issue 3” label is Issue 4.
3. Model the difference between a clue, a possible system concern, and a repair conclusion.

Do not ask students to research repair instructions. A warning light or code points toward a system; it does not prove the failed part or authorize a repair.

## Warm-Up: Clue or Conclusion? (5 min)

Sort three statements: “the temperature light is on,” “steam is visible,” and “the water pump failed.” The first two are supplied clues. The third is a conclusion that requires trained inspection.

## Activity 1: Tool Limits (7 min)

Read FYF p. 153. A dashboard light alerts the driver to a system. A code reader narrows the investigation. Neither proves a repair or that the vehicle is safe. Students restate one boundary orally or in a notebook before continuing.

## Activity 2: Four Clue Sets (18 min)

Students use FYF p. 154 and discuss four rows. The workbook already provides the clue sets and response areas, so no second default packet is needed. For each case, students identify:

1. two exact clues;
2. a broad possible system concern;
3. one conclusion the clues do **not** prove; and
4. the trained inspection or approved information still needed.

Accept broad system labels such as lubrication/engine-temperature, electrical/charging, cooling/temperature, and tire/steering. Do not score a guessed failed part as the intended answer.

## Activity 3: Priority and Safe Next Step (15 min)

Students complete FYF p. 155 and rank which two cases require the quickest stop-and-inspect response. Strong reasoning normally places the steam/very-hot case and the soft-tire/pulling case at the top because the supplied clues indicate immediate heat or control risk. Oil-plus-heat may also be defended as immediate when the student names the combined evidence. The battery case still needs service; “not top two” does not mean safe to ignore.

For each top case, students write a broad next step: stop using the fictional vehicle, notify the responsible adult/customer, and route it to an authorized technician or approved procedure. They do not prescribe a repair.

## Exit Check (5 min)

**EXIT TICKET** (Mini-Case) · [Printable PDF](../../resources/exit-tickets/4sw-wk6-day1-analytical-reasoning-what-the-clues-support.pdf):

Correct the claim that a code already proves the failed part. Then name one different career task that uses the same clue-to-conclusion reasoning.

Scenario: A coworker says, “The code already told us the broken part, so we can skip the inspection.”

1. Name one clue from the fictional case.

2. Explain one conclusion the clue does not prove.

3. Write one safe, authorized next step.

*(d(4)(B))*

## Monitoring and Supports

- **Minute 12:** students label clues without naming a failed part. If more than one-third diagnose, rework the supplied temperature-light model.
- **Minute 28:** all four concerns and ranks are present. **Minute 42:** both plans name stop/protect, handoff, and missing evidence.
- Initial FYF pp. 154-155 during work time. Students submit only the private exit; collect one fallback only from students assigned that route.
- Safe trim: complete two full evidence rows, rank all four, and protect both plans plus the exit; finish the other evidence rows during recovery.

- Evidence names what is supplied; inference names what might be true; conclusion requires confirmation.
- Use the adjacent text description if the workbook image is difficult to read.
- Allow oral rehearsal, typing, dictation, annotation, or paper.
- Absence route: the three-page fallback repeats all four clue sets; no partner or website is required.
