# Day 1: Analytical Reasoning — What the Clues Support

## Lesson Overview

| | |
|---|---|
| **Time** | 50 minutes |
| **Objective** | Separate observations from conclusions, compare four fictional warning-light clue sets, and choose a safe inspection priority using evidence |
| **TEKS** | d(4)(B) |
| **Deliverable** | Truck Evidence and Priority packet |
| **Materials** | FYF pp. 153-155, CCE packet, licensed Canvas images |

## Before Class

1. Post the packet and Canvas annotation activity.
2. Project the four fictional clue sets. Tell students that the workbook's repeated second “Issue 3” label is Issue 4.
3. Model the difference between a clue, a possible system concern, and a repair conclusion.

Do not ask students to research repair instructions. A warning light or code points toward a system; it does not prove the failed part or authorize a repair.

## Warm-Up — Clue or Conclusion? (5 min)

Sort three statements: “the temperature light is on,” “steam is visible,” and “the water pump failed.” The first two are supplied clues. The third is a conclusion that requires trained inspection.

## Activity 1: Tool Limits (7 min)

Read FYF p. 153. A dashboard light alerts the driver to a system. A code reader narrows the investigation. Neither proves a repair or that the vehicle is safe. Students copy one sentence for each boundary into the packet.

## Activity 2: Four Clue Sets (18 min)

Students use FYF p. 154 and complete four rows:

1. two exact clues;
2. a broad possible system concern;
3. one conclusion the clues do **not** prove; and
4. the trained inspection or approved information still needed.

Accept broad system labels such as lubrication/engine-temperature, electrical/charging, cooling/temperature, and tire/steering. Do not score a guessed failed part as the intended answer.

## Activity 3: Priority and Safe Next Step (15 min)

Students rank which two cases require the quickest stop-and-inspect response. Strong reasoning normally places the steam/very-hot case and the soft-tire/pulling case at the top because the supplied clues indicate immediate heat or control risk. Oil-plus-heat may also be defended as immediate when the student names the combined evidence. The battery case still needs service; “not top two” does not mean safe to ignore.

For each top case, students write a broad next step: stop using the fictional vehicle, notify the responsible adult/customer, and route it to an authorized technician or approved procedure. They do not prescribe a repair.

## Exit Check (5 min)

**EXIT TICKET** (Mini-Case) · [Printable PDF](../../resources/exit-tickets/4sw-wk6-day1-analytical-reasoning-what-the-clues-support.pdf):

Scenario: A coworker says, “The code already told us the broken part, so we can skip the inspection.”

1. Name one clue from the fictional case.

2. Explain one conclusion the clue does not prove.

3. Write one safe, authorized next step.

*(d(4)(B))*

## Monitoring and Supports

- Evidence names what is supplied; inference names what might be true; conclusion requires confirmation.
- Use the adjacent text description if the workbook image is difficult to read.
- Allow oral rehearsal, typing, dictation, annotation, or paper.
- Absence route: the CCE packet repeats all four clue sets; no partner or website is required.
