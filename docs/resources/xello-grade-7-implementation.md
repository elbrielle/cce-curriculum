# Xello Grade 7 Implementation Guide

## Governing rule

This is a Grade 7 CCE course. Required Xello work must be:

1. assigned to Grade 7 in Bowie Middle School's live Completion Standards; or
2. explicitly named in the original coordinator workbook,
   `CCE_Comprehensive_Scope_Sequence.xlsx`.

A task from another grade may appear only as the smallest verified
prerequisite-support action needed to launch a selected task. Call it
**prerequisite support**, not a Grade 7 completion standard. Check the student
experience when the educator resource panel is ambiguous.

## Important Matchmaker clarification

The educator panel says Matchmaker requires students to set an after-high-school
goal. In the demo-student flow, that question appears inside the Matchmaker
launch. Students can answer it and start Matchmaker without completing the
separate Grade 8 **After high school goal** task. Do not assign that separate
task.

## Before a Xello lesson

1. Sign in through ClassLink and open **Completion Standards → Grades 6–12**.
2. Confirm the task has a green check in the Grade 7 column or appears in the
   original coordinator workbook.
3. Open **Resources** and record the instructional time, on-task time, and
   listed prerequisites.
4. Check any ambiguous prerequisite in a demo-student account. Decide whether
   it is an inline prompt, a previously sequenced task, or a separate support
   action.
5. Put the exact student click path, recovery route, and **You Are Done When**
   evidence in the Student Guide and editable deck.
6. Keep Xello files and screenshots inside authenticated Canvas. Do not publish
   licensed resources in GitHub or the public planning mirror.

## Completion and response-home rule

- Xello completion stays in Xello.
- A workbook, paper, OneNote, or Canvas reflection is assigned only when it adds
  new thinking; students do not copy a completed Xello response elsewhere.
- Teachers select one response home before class.
- Every Xello lesson needs an equivalent non-Xello evidence route for an account
  or service outage, without pretending that the fallback completed the Xello
  task.
