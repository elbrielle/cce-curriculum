## Lesson Overview

| | |
|---|---|
| **Time** | 50 minutes |
| **Objectives** | Turn observation notes into a bounded evidence report; deliver one organized 30–45 second professional briefing |
| **TEKS** | d(1)(C), d(4)(C) |
| **Deliverable** | Individual report + live, private recorded, or teacher-conference oral briefing |
| **Materials** | Locked images, shared five-page evidence report begun on Day 4, briefing planner, student-visible feedback guide, private Canvas Assignment |

## Warm-Up (5 min)

Rewrite “Something is wrong with this house” as one precise observation and one cautious possibility.

## Activity 1: Report Model and Boundary (5 min)

Model one finding. Use a fictional student analyst ID or fictional inspector name—not a student legal name. Each finding contains:

- image and area;
- visible observation;
- what it could indicate;
- evidence limit or next check;
- qualified professional who should evaluate it.

The report does not diagnose, price repairs, rank purchase decisions, or promise safety.

## Activity 2: Complete the Evidence Report (25 min)

Students revise the shared five-page evidence report begun on Day 4 rather than recopying the findings into a second packet. They complete five image blocks, the thermal boundary, and the overall summary. A neutral image still requires the area checked, visible evidence, and the limit of the photograph.

Teacher monitoring sequence:

1. every row begins with a visible observation;
2. possibilities use “could” or “may”;
3. no row claims mold, a leak source, code violation, or safe condition as proven;
4. each row names an appropriate qualified follow-up role.

## Activity 3: Individual Professional Briefing (12 min)

Every student prepares and delivers one 30–45 second briefing through a live teacher conference, private Canvas audio/video recording, or an accommodation-aligned oral/AAC route.

Briefing jobs:

1. name the image/area;
2. state the visible evidence;
3. explain one cautious possibility and limit;
4. recommend the qualified role for further evaluation.
5. name the work product that worker would create or use next.

Public presentation is optional practice and is not required. There is no cold team jigsaw.

## Exit Check and Private Submission (3 min)

Submit the report and oral evidence. Then answer: Which word or phrase kept your report from overstating the evidence?

## Teacher Key and Scoring

Use the Day 4 interpretation guide. Score four criteria, 0–4 each:

1. visible evidence accuracy;
2. cautious inference and evidence limit;
3. correct career/qualified-role connection;
4. organized professional briefing.

Art, accent, grammar, H&L state, recording polish, and submission mode do not determine the score unless meaning is unclear. Keep the Assignment unpublished and ungraded until the six-weeks Minor/Major map and 40/60 weighting are verified.

## Supports and Fallback

Provide sentence frames, bilingual labels, a model/non-example, speech-to-text for the report, and a private teacher-conference briefing. Absent students use the same locked images and complete an individual route. H&L favorites, a partner, and public speaking are not required.
