# Day 4: Transferable Skills in Veterinary Work

## Daily Learning Contract

- **Topic:** Transferable Skills
- **Objective:** Students will identify how one skill transfers between veterinary work and another career using fixed FYF/CCE evidence and a private reflection.
- **TEKS:** d(4)(B)
- **Demonstration of Learning:** Private reflection comparing how one transferable skill appears in veterinary work and another career.

## 50-minute plan

- **Think-Pair-Share -- 4 minutes:** Define a transferable skill and name two places it can be used.
- **Fixed evidence review -- 18 minutes:** Use the veterinary career guide, FYF evidence, and the five-skill bank to connect skills to career tasks.
- **Two-career comparison -- 20 minutes:** Compare how one skill appears in veterinary work and another career.
- **Private reflection -- 8 minutes:** Name the skill, both visible work actions, and one way the student can practice it.

No live platform is required. Do not require profile screenshots or public sharing of a student's self-rating.

## Evidence and supports

- private Transferable Skills reflection, typed or on the supplied PDF
- Veterinary Career Evidence Guide and FYF career/task evidence
- five-skill bank: observation, communication, problem solving, teamwork, and organization
- bilingual labels, read-aloud, chunking, and oral rehearsal

## Next-day setup and monitoring

- **Students:** provide the one-page reflection digitally or print one copy only for students using the paper route.
- **Teacher:** project the five-skill bank and one complete veterinary task-to-skill model. Student work and reflection remain individual and private.
- **Minute 12 check:** each student has selected a veterinary task and named the skill visible in that task.
- **Minute 30 checkpoint:** each student has a second-career task that uses the same skill in a different way.
- **Pivot:** use the completed veterinary assistant model and teacher-provided second-career example when prior evidence is missing.
- **Trim:** reduce partner share and provide one completed evidence row. Preserve the two-career comparison and private reflection.
