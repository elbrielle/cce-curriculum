# Climber Notes Index

Teacher-held presentation decks for FYF workbook activities, delivered by H&L 2026-08-05 (Google Drive export). The `.pptx` binaries live in the main repo at `cce-curriculum/resources/climber-notes/` (gitignored); the tracked `.txt` files here are text extracts (slide text + speaker notes + image counts) for searching. Decks are heavy on images (case photos, X-rays, scan images) that the extracts only count, not show — open the deck itself when the visual matters.

**Citation convention:** `(Climber Notes: "Deck Name", slide N)` — these are teacher materials, never student-facing citations.

## Notes for implementers

- Deck slide decks follow a pattern: title → narrative hook → activity/reference table → H&L app instruction slide → Class Discussion slide. App-instruction slides name the exact app path (e.g., Profile → Discover Your Core) — use these for `> [H&L PLATFORM]` lines instead of inventing app navigation.
- Image-heavy decks (Clinton Lake Case evidence, Smile Squad X-rays, Ultrasound scans) are the case materials the workbook's "Climber Notes" callouts point to. Lesson plans should direct the teacher to project the deck, not reproduce the images.
