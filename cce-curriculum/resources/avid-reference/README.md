# AVID Reference Library

This directory supports a private source audit of the Hainlen AVID 2 pacing calendar and selected owner-shared resources.

- `source/` is intentionally Git-ignored. It may contain licensed or shared-only documents, screenshots, student names, school logistics, and dated local information.
- Source-derived page renders, text extracts, converted files, and audit previews are equally private. Keep them only under ignored `source/`, `tmp/`, or `.tmp/` paths; never stage them.
- Do not upload the source library to GitHub, the legacy public site, or public Canvas files.
- Tracked curriculum may describe an instructional pattern learned from the sources, but it must not copy licensed text, student information, or stale local claims.
- Any source adopted into CCE must be rebuilt for grade 7, aligned to the CCE TEKS and existing lesson contract, checked for duplicate work, and staged unpublished in Canvas for review.

The current analysis is in `cce-curriculum/notes/avid-to-ccr-reconciliation.md`.
